What was checked

SQLite integrity and foreign-key checks before and after the rehearsal. Failed batches roll back as one transaction. Removed tables, missing column names and falling row counts require review. Column renames also request review.

What this does not prove

Row counts do not detect rewritten values. This is not a deployment, a production lock benchmark, or a hostile-SQL sandbox. *Row writes include trigger effects and count writes, not distinct rows.
